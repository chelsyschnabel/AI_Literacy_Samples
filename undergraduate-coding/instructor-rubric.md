# AI Literacy: Undergraduate Computer Science Rubric  
**Total Points:** 120 points

### Technical Implementation and Code Quality (35 points)
**Exemplary (32-35 points)**
- Implements complex data structure (AVL tree) with full functionality
- Code demonstrates mastery of object-oriented programming principles
- Uses advanced Python features appropriately (type hints, proper encapsulation)
- Code is efficient, readable, and follows professional standards

**Proficient (25-31 points)**
- Implements data structure with mostly correct functionality
- Shows good understanding of OOP principles
- Uses some advanced features appropriately
- Code is generally well-written with minor issues

**Developing (18-24 points)**
- Implements basic functionality with some errors
- Basic understanding of OOP with some confusion
- Limited use of advanced language features
- Code works but has style or efficiency issues

**Beginning (0-17 points)**
- Major errors in implementation or incomplete functionality
- Poor understanding of OOP principles
- No use of advanced features
- Code is poorly written or non-functional

### AI-Assisted Code Review and Improvement (30 points)
**Exemplary (27-30 points)**
- Uses AI strategically for code review while maintaining full understanding
- Incorporates AI suggestions thoughtfully with clear reasoning
- Uses AI to learn professional development practices
- Demonstrates sophisticated understanding of AI's role in software development

**Proficient (21-26 points)**
- Uses AI appropriately for code improvement
- Generally incorporates useful AI suggestions
- Shows learning of some professional practices through AI
- Good understanding of AI assistance in development

**Developing (15-20 points)**
- Basic use of AI for code review with limited strategic thinking
- Inconsistently incorporates AI feedback
- Limited learning of professional practices
- Uncertain understanding of AI's development role

**Beginning (0-14 points)**
- Inappropriate AI use or over-dependence on AI solutions
- No evidence of thoughtful incorporation of suggestions
- No learning of professional practices
- No understanding of appropriate AI integration

### Algorithmic Analysis and Complexity Understanding (25 points)
**Exemplary (23-25 points)**
- Demonstrates deep understanding of time/space complexity
- Uses AI effectively to verify and deepen complexity analysis
- Explains theoretical guarantees of AVL trees clearly
- Shows sophisticated understanding of algorithmic trade-offs

**Proficient (18-22 points)**
- Shows good understanding of complexity concepts
- Uses AI appropriately to support complexity analysis
- Generally explains AVL properties correctly
- Shows awareness of basic algorithmic trade-offs

**Developing (13-17 points)**
- Basic understanding of complexity with significant gaps
- Limited effective use of AI for analysis support
- Confused about some AVL properties or guarantees
- Little awareness of algorithmic trade-offs

**Beginning (0-12 points)**
- Poor understanding of complexity analysis
- No meaningful use of AI for complexity understanding
- Cannot explain AVL properties or guarantees
- No understanding of algorithmic considerations

### Professional Development and Documentation (20 points)
**Exemplary (18-20 points)**
- Excellent code documentation and professional commenting
- Demonstrates learning of industry best practices through AI interaction
- Creates comprehensive testing and performance analysis
- Shows preparation for professional software development

**Proficient (14-17 points)**
- Good documentation with appropriate comments
- Shows learning of some professional practices
- Adequate testing and analysis
- Shows some preparation for professional work

**Developing (10-13 points)**
- Basic documentation with limited professional quality
- Limited learning of professional practices
- Minimal testing or performance analysis
- Little evidence of professional development

**Beginning (0-9 points)**
- Poor or no documentation
- No evidence of learning professional practices
- No testing or performance consideration
- No preparation for professional development

### Reflection and AI Ethics Understanding (10 points)
**Exemplary (9-10 points)**
- Sophisticated reflection on AI's role in learning and development
- Demonstrates clear understanding of AI ethics in professional context
- Shows growth in both technical skills and AI literacy
- Articulates future applications of AI-assisted development

**Proficient (7-8 points)**
- Good reflection on AI-assisted learning experience
- Shows understanding of basic AI ethics in development
- Demonstrates some growth in skills and understanding
- Some consideration of future AI use

**Developing (5-6 points)**
- Basic reflection with limited insight
- Uncertain understanding of AI ethics
- Little evidence of meaningful growth
- No consideration of future applications

**Beginning (0-4 points)**
- No meaningful reflection on learning experience
- No understanding of AI ethics in professional context
- No evidence of growth or learning
- No consideration of AI's role in future work
